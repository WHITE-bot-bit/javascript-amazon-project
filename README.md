# JavaScript Amazon Project

A simple Amazon-inspired e-commerce website built using HTML, CSS, and JavaScript.

## Features

- Product listing
- Shopping cart
- Checkout page
- Order tracking
- Responsive design
- Dynamic cart updates

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```
├── backend/
├── data/
├── images/
├── scripts/
├── styles/
├── test-jasmine/
├── tests-Simple/
├── amazon.html
├── checkout.html
├── orders.html
├── tracking.html
└── index.html
```
